01

Machine numbers & floating point

Problem

Finite memory versus infinitely many digits of a real number: values must be truncated.

FP notation
x = ±0.a1…at · βq

β = 2 (bits), t = mantissa digits, q = exponent (position of the radix point).

Rounding vs truncation

Truncation: err ≤ β1−t. Rounding: err ≤ ½ β1−t = ε. Rounding is always better — the bound is halved.

Key advantage

The relative error depends only on t, not on q — i.e. not on the magnitude of the number.

FP operations

Product: well conditioned (≈ 3ε). Sum: ill conditioned when x + y → 0.

Catastrophic cancellation

Subtracting two nearby numbers destroys significant digits. Quadratic equation — stable form:

x1 = (−b − sign(b)√Δ) / 2a
x2 = c / (a x1)
02

Linear algebra

Vectors & matrices

x ∈ ℝn is a column; A ∈ ℝm×n. The linear map Ax = y is a linear combination of the columns of A.

Rank

Number of linearly independent columns = dimension of the image. Full rank: rank(A) = n.

Kernel & range
ker(A) = {x : Ax = 0} ∋ 0
range(A) = span(columns of A)
Systems Ax = y

m = n, full rank → unique solution.

m > n overdetermined: no exact solution; minimise ǁrǁ with r = Ax − y (residual).

m < n underdetermined: infinitely many solutions; the one of minimum norm is chosen.

Special matrices

Symmetric: A = AT. Orthogonal: QT = Q−1 → preserves the 2-norm.

03

Norms

Axioms
ǁxǁ = 0 ⇔ x = 0
ǁλxǁ = |λ| ǁxǁ
ǁx + yǁ ≤ ǁxǁ + ǁyǁ
Vector norms
ǁxǁ1 = Σi |xi|  (Manhattan)
ǁxǁ2 = √(xTx)  (Euclidean)
ǁxǁ∞ = maxi |xi|
Induced norm
ǁAǁ = supx≠0 ǁAxǁ / ǁxǁ
Matrix norms
ǁAǁ1 = max column Σi|aij|
ǁAǁ∞ = max row Σj|aij|
ǁAǁ2 = σ1 (largest singular value)

The 2-norm requires the SVD or the eigenvalues.

04

Condition number

Definition
K(A) = ǁAǁ · ǁA−1ǁ
Properties

K(A) ≥ 1 always. K(A) = 1 is the minimum, attained by orthogonal matrices. It depends only on A, never on the algorithm used.

Link with the error
ǁx − x̃ǁ / ǁxǁ ≤ K(A) · ǁb − b̃ǁ / ǁbǁ
ǁb − b̃ǁ / ǁbǁ ≤ ε  (FP representation)
⇒ upper bound ≤ K(A) · ε
Generalised K₂ (SVD)

K2(A) = σ1 / σk, where σk is the smallest non-zero singular value.

Residual ≠ K(A)

The residual measures the quality of the algorithm; K(A) measures the sensitivity of the problem.

05

Eigenvalues & eigenvectors

Definition
Ax = λx, λ ∈ ℂ, x ∈ ℂn
det(A − λI) = 0 (characteristic polynomial)
eigenvector ∈ ker(A − λI)
Property 1

Distinct eigenvalues → linearly independent eigenvectors; n distinct ones give a basis of ℝn.

Property 2

Similar matrices B = C−1AC share the same eigenvalues.

Property 3

If A is invertible, A−1 has the same eigenvectors and reciprocal eigenvalues 1/λ.

Symmetric matrices

Spectral theorem: A = QΛQT. Real eigenvalues, orthogonal eigenvectors — only for square symmetric A.

06

Singular value decomposition

Definition
A = UΣVT

Holds for every matrix, rectangular included; it generalises the spectral theorem.

Singular values

σi = √(eigenvalues of ATA), vi = eigenvectors of ATA. All σi ≥ 0, real, ordered σ1 ≥ σ2 ≥ … ≥ σn.

Sum of rank-1 terms

A = Σi σi ui viT — each outer product has rank 1.

Low-rank approximation

Ar = Σi=1r σi ui viT, with ǁA − Arǁ2 = σr+1. Eckart–Young: this is the best possible approximation.

Pseudo-inverse A†
A† = VΣ†UT
Σ† = diag(1/σ1, …, 1/σk, 0, …, 0)
Applications

PCA (SVD of X → principal components), image compression, regularisation when K(A) is large.
