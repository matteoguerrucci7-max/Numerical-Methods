Numerical Methods · Linear systems

Direct, iterative and gradient methods

Solving A x = b with A ∈ ℝn×n. Three branches, distinguished by what happens to A: it is modified, it is never touched, or it is symmetric positive definite.

O(n³) → O(n²) → matrix–vector
3 branches · study reference sheet
Branch 1 · A is modified

Direct methods

Transform the system into an equivalent triangular one, then solve by substitution.

1 · Triangular systems

Lower: aij = 0 for every j > i. Upper: aij = 0 for every i > j. det A is the product of the diagonal entries, so A is invertible ⇔ aii ≠ 0 for all i.

Forward substitution
x1 = b1 / a11
xi = ( bi − Σj=1i−1 aij xj ) / aii, i = 2,…,n
Backward substitution
xn = bn / ann
xi = ( bi − Σj=i+1n aij xj ) / aii, i = n−1,…,1

Cost. O(i) operations per xi, so about n²/2 in total: O(n²) ≪ O(n³) of the inversion.

Remark

Always prefer turning a general system into a triangular one (Gauss / LU) and then substituting, rather than inverting A directly.

2 · Gaussian elimination and pivoting

Idea. A x = b ⟶ U x = b̃ with U upper triangular, through elementary row operations — linear combinations that leave the solution unchanged.

mik = aik(k−1) / akk(k−1)

Multipliers used to zero the entries below the pivot akk, column by column.

Pivoting — two distinct motivations

1 Necessity. If akk(k−1) = 0 the algorithm breaks down (division by zero): swap that row with a lower one having a non-zero entry in the column.

2 Numerical stability. Even with a non-zero pivot, a small one makes the multiplier mik large, amplifying the rounding errors already present.

Partial pivoting
ℓ = argmaxk |aik(k−1)| ⟶ swap row k ↔ row ℓ
Remark — do not confuse

Related to, but distinct from, catastrophic cancellation: there the problem is a subtraction of nearby numbers, here it is a division by a small number producing an amplifying factor — conceptually closer to the condition number.

3 · LU factorisation

The Gauss operations are encoded in a lower triangular L (ones on the diagonal, the multipliers mik below it).

A = L U
with pivoting: P A = L U

P is a permutation matrix.

Practical advantage

Factorising A once (cost ≈ ⅓n³) allows A x = b to be solved for many different right-hand sides b: each further solve is just two triangular systems, O(n²) each.

Branch 2 · A is never modified

Iterative methods

A sequence x(k) → x built from matrix–vector products only.

Motivation — sparse matrices

Useful when A is large and sparse: Gaussian elimination causes fill-in — zeros become non-zero during elimination — destroying the sparse structure and with it the memory and speed advantage.

General scheme — preconditioner M
x(k+1) = x(k) + M−1( b − A x(k) ) = x(k) + M−1 r(k)
r(k) = b − A x(k)  (residual)

M must be invertible and strikes a compromise: (1) the system with M must be easy to solve; (2) M ≈ A, to converge in few iterations.

Extreme case

M = A converges in one step, but the system to solve is the original problem itself.

M = DJacobi M = D + LGauss–Seidel M = (1/α) IRichardson

Jacobi  M = D

A = D + E, with D the diagonal of A and E = A − D.

D x(k+1) = b − E x(k) ⟹ x(k+1) = D−1( b − E x(k) )
xi(k+1) = ( bi − Σj≠i aij xj(k) ) / aii

Error e(k) = x(k) − x gives e(k+1) = −D−1E · e(k), hence ‖e(k)‖ ≤ ‖D−1E‖k ‖e(0)‖.

convergence ⇔ ǁD−1Eǁ < 1
|aii| > Σj≠i |aij|  ∀ i
Proof — strict diagonal dominance

With the matrix ∞-norm, ‖D−1E‖∞ is the maximum over the rows of ( Σj≠i|aij| / |aii| ), which is < 1 row by row exactly under diagonal dominance.

Gauss–Seidel  M = D + L

A = D + L + U, with L strictly lower and U strictly upper triangular.

aii xi(k+1) = bi − Σj=1i−1 aij xj(k+1) − Σj=i+1n aij xj(k)
Key point

For j < i the values already updated within the same iteration, xj(k+1), are used: an in-place update. This is why Gauss–Seidel converges faster than Jacobi under the same hypotheses — diagonal dominance guarantees convergence of both.

Richardson  M = (1/α) I

x(k+1) = x(k) + α ( b − A x(k) ) = x(k) + α r(k)

α is a free scalar, not tied to any entry of A. Convergence: ‖I − αA‖ < 1.

Case A SPD, 2-norm — λ₁ ≥ … ≥ λₙ > 0
ǁI − αAǁ2 = maxi |1 − αλi| ⟹ 0 < α < 2/λ1
α* = 2 / (λ1 + λn)
ρ = ǁI − α*Aǁ2 = ( K(A) − 1 ) / ( K(A) + 1 )
Link with Chapter 1

The convergence rate depends explicitly on the condition number: K(A) ≈ 1 ⇒ ρ ≈ 0 (fast); K(A) large ⇒ ρ → 1 (very slow).

Convergence rate

‖e(k)‖ ≤ ρk‖e(0)‖ ≤ ε‖e(0)‖
k ≥ log(ε) / log(ρ)  (ρ < 1)

With ε = 0.1 (one decimal digit): k > log(10)·K(A)/2 ≈ K(A). The number of iterations needed to gain one decimal digit is roughly K(A): if K(A) ≈ 1000, one digit is gained about every 1000 iterations.

Remark — ε ≠ eps

ε is a convergence tolerance chosen by the user; eps (machine precision, Chapter 1) is a fixed limit of the floating-point representation. ρ and ε concern the speed of an iterative algorithm, independently of machine precision.

Practical stopping criteria

(a) On the residual. ‖A x(k) − b‖ ≤ C · Tol, with C = ‖b‖ or ‖A‖ (1- or ∞-norm, cheap to compute).

(b) On successive iterates. ‖x(k+1) − x(k)‖ ≤ ‖x(k)‖ · Tol.

Branch 3 · A is SPD

Gradient-type methods

Symmetry is already part of the definition of SPD; it is not a separate requirement.

Linear system ↔ minimisation problem

φ(x) = ½(x, Ax) − (b, x)
A x = b ⟺ φ(x) = minz∈ℝⁿ φ(z)
Proof ① solution ⟹ minimum

∇φ(z) = Az − b (using the symmetry of A). If A x = b then ∇φ(x) = 0, so x is stationary. Since A is SPD, φ is convex (its Hessian is A, positive definite) and a stationary point of a convex function is the unique global minimum.

Proof ② minimum ⟹ solution

φ(x+z) = φ(x) + ½(z, Az) − (z, Ax−b) ≥ φ(x) − (z, Ax−b), because ½(z,Az) ≥ 0 for A SPD. If x is a minimum, φ(x+z) ≥ φ(x) for every z, hence (z, Ax−b) ≥ 0 for all z, including −z. Substituting z → tz with t ∈ ℝ gives (t²/2)(z,Az) − t(z,Ax−b) ≥ 0: for this to hold for every t, small and of either sign, the linear coefficient must vanish. Therefore (z, Ax−b) = 0 for all z ⟹ A x = b.

Observation — A not SPD

Perturbing φ(x+εz) and differentiating with respect to ε, the critical point solves ½(A + AT)x = b instead of A x = b; if A is symmetric, A x = b is recovered. For it to be a minimum rather than a saddle point, all eigenvalues of A must be positive.

The residual is the steepest-descent direction

∇φ(x(k)) = A x(k) − b = − r(k)
x(k+1) = x(k) + αk r(k)

The gradient points in the direction of steepest increase, so its opposite r(k) is the direction of steepest descent. Ortomin and the gradient method share this scheme: only the choice of αk differs — in Richardson α is fixed, here αk changes at every iteration.

Ortomin — minimises the residual

r(k+1) = r(k) − αk(A r(k)), so r(k+1) ∈ r(k) + span(A r(k)): a line as αk varies. Minimising ‖r(k+1)‖ means finding the point of that line closest to the origin — an orthogonal projection, with r(k+1) ⊥ A r(k).

(r(k+1), A r(k)) = 0 ⟹ αk = (r(k), A r(k)) / (A r(k), A r(k))
ǁr(k+1)ǁ² = ǁr(k)ǁ² − (A r(k), r(k))² / ǁr(k)ǁ²
Advantage

It only uses the symmetry of the scalar product, not of A: it works for non-SPD A as well, provided (Az, z) ≠ 0 for the current residual. It can fail if A has eigenvalues of opposite sign.

Gradient method — minimises the error in the A-norm

ǁzǁA = √(z, Az)  (energy norm, defined only for A SPD)
0 = (e(k+1), A r(k)) ⟹ αk = (r(k), r(k)) / (r(k), A r(k))

One minimises ‖e(k+1)‖A² along the line e(k+1) ∈ e(k) + span(r(k)), requiring A-orthogonality between e(k+1) and r(k). Convergence is comparable to Richardson with the optimal step, but αk is recomputed at every iteration; in practice it still shows a slow “zig-zag” behaviour in many cases.

Careful — do not mix the two formulas

Ortomin: (r, Ar) / (Ar, Ar). Gradient: (r, r) / (r, Ar). The position of Ar changes both numerator and denominator.

Conjugate gradient

The error is minimised no longer along a single line but over a plane, using a new direction p(k) instead of the residual alone, with e(k+1) A-orthogonal to both p(k) and p(k−1).

x(k+1) = x(k) + αk p(k),   e(k+1) ∈ e(k) + span(p(k), p(k−1))
αk = (r(k), p(k)) / (A p(k), p(k))
p(k) = r(k) − βk p(k−1),   βk = (r(k), A p(k−1)) / (p(k−1), A p(k−1))

αk follows from 0 = (e(k+1), A p(k)) = (r(k), p(k)) − αk(A p(k), p(k)); if p(k) = r(k) the plain gradient formula is recovered. βk follows from (e(k+1), A p(k−1)) = 0, using the symmetry of A.

Remarkable property

The directions p(0), p(1), … are mutually A-orthogonal, not just consecutive ones. In an n-dimensional space there cannot be more than n mutually orthogonal directions, so the conjugate gradient reaches the exact solution in at most n steps (in exact arithmetic) — far more efficient than the plain gradient method, which can zig-zag indefinitely.
