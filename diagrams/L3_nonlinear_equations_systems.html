01

Existence of zeros & conditioning

Problem

Given f: ℝ → ℝ, find y with f(y) = 0. Such a y is a root, or zero, of f.

Theorem — existence of zeros
f continuous on [a,b], f(a)·f(b) < 0
⇒ ∃ y ∈ (a,b) : f(y) = 0

The sign change forces the graph to cross the axis, but the proof says nothing about where. That gap is what the numerical methods fill.

Conditioning — derivation

Perturb f vertically by ε (f̃ = f + ε) and let ỹ be the perturbed root, Δx = ỹ − y. Expanding around y:

0 = f(y) + f′(y)Δx + O(Δx²) + ε
f(y) = 0 ⇒ Δx ≈ −ε / f′(y)
Reading the estimate

The smaller |f′(y)| — the flatter the curve at the crossing — the larger the displacement for the same ε: the root is ill-conditioned. Extreme case f′(y) = 0 (double root, e.g. f(x) = x²): maximal sensitivity, whatever algorithm is used.

Residual ≠ error

As with K(A) for linear systems, conditioning is a property of the problem (f, y), not of the algorithm. Since |f(ck)| ≈ |f′(y)|·|ck − y|, a tiny residual is no evidence of a small error when |f′(y)| is small.

02

Bisection

Hypotheses

f continuous on [a,b] and f(a)·f(b) < 0 — exactly the hypotheses of the existence theorem, turned into an algorithm.

Construction
ck = (ak + bk) / 2
f(ak)·f(ck) < 0 ⇒ ak+1=ak, bk+1=ck
else ⇒ ak+1=ck, bk+1=bk

Either branch preserves the bracketing and halves the interval — always, regardless of how f behaves inside it.

Stopping criteria

(a) Residual. |f(ck)| < C·Tol — can deceive on ill-conditioned roots: small residual does not imply small error.

(b) Interval width. |bk − ak| < C·Tol — more robust: it never depends on the values of f, only on the geometric count of halvings, and does not even require f to be differentiable.

Convergence
ek = |y − ck| ≤ bk − ak
bk − ak = (1/2)k(b0 − a0)

Linear convergence with fixed rate 1/2, independent of the conditioning of the root.

Cost per decimal digit

Requiring (1/2)k ≤ 1/10 gives k ≥ ln10 / ln2 ≈ 3.32: about 3–4 iterations per digit, always. Slow, but with a guarantee no other method here offers.

03

Newton's method

Construction — tangent line
tangent: y − f(xk) = f′(xk)(x − xk)
set y = 0 ⇒ xk+1 = xk − f(xk) / f′(xk)
Starting point

x₀ can be any point — no bracketing f(a)f(b) < 0 required. In exchange convergence is not guaranteed: far from y, or near a point with f′ ≈ 0, the nearly horizontal tangent can throw the iteration arbitrarily far, or make it diverge.

Error analysis — Taylor
0 = f(y) = f(xk) + f′(xk)(y−xk) + ½f″(ξk)(y−xk)²
÷ f′(xk) ⇒ y − xk+1 = −½[f″(ξk)/f′(xk)](y−xk)²
ek+1 ≈ Mk ek², Mk = ½ f″(ξk)/f′(xk)
Quadratic convergence

The next error is proportional to the square of the current one — correct digits roughly double per iteration. Requires Mk uniformly bounded; it fails when f′ → 0 near the root, the same phenomenon as an ill-conditioned root.

Newton as fixed point
g(x) = x − f(x)/f′(x), xk+1 = g(xk)
quotient rule: g′(x) = f(x)f″(x) / [f′(x)]²
f(y) = 0 ⇒ g′(y) = 0

A second, independent proof of quadratic convergence via the fixed-point theory of block 06 — valid for simple roots, f′(y) ≠ 0.

04

Secant method

Idea

Approximate the derivative in Newton's step by a difference quotient built from two points already computed.

f′(xk) ≈ ( f(xk) − f(xk−1) ) / ( xk − xk−1 )
xk+1 = xk − f(xk)·(xk − xk−1) / ( f(xk) − f(xk−1) )
Geometry

Newton uses the tangent at one point; the secant uses the line through (xk−1, f(xk−1)) and (xk, f(xk)) — hence two starting points x₀, x₁ instead of one.

Advantage

No explicit computation of f′(x) — valuable when the derivative is expensive, complicated, or not available in closed form.

Cost

Superlinear but not quadratic convergence: order ≈ 1.618, the golden ratio. Slower per iteration than Newton, but it never needs a reliable evaluation of f′.

05

Newton for systems

Problem

Given f: ℝn → ℝn, find x̃ with f(x̃) = 0: a vector of n functions vanishing simultaneously.

Why no bisection

The existence-of-zeros theorem does not generalise: in ℝn there is no natural order relation, so "a < x < b" is meaningless for vectors and there is no interval to halve.

Taylor in ℝⁿ & iteration
f(z) = f(x) + Jf(x)(z−x) + O(‖z−x‖²)
set model to 0: Jf(xk) d = −f(xk)
xk+1 = xk + d

Jf(x) is the Jacobian, the n×n matrix of partial derivatives generalising f′(x). One cannot divide by it: a linear system is solved at each iteration.

Stopping criteria

Successive iterates: ‖xk+1 − xk‖ ≤ C·Tol with C = ‖xk‖. Residual: ‖f(xk)‖ ≤ C·Tol with C = ‖f(x₀)‖ — C makes the test relative rather than absolute.

Theorem — local convergence

Let f be at least C¹ on a convex Ω, and assume: (1) ∃ x* ∈ Ω with f(x*) = 0; (2) Jf(x*) invertible with ‖Jf−1(x*)‖ < C; (3) Jf Lipschitz-continuous near x*. Then there is a ball B(x*, r) such that Newton converges for every x₀ ∈ B(x*, r). Purely local: no guarantee if you start far away.

Link with the linear-systems chapter

Each Newton step is a linear solve (Gauss / LU, or iterative). To contain the cost the Jacobian is often frozen for several iterations instead of being recomputed and refactorised every time.

06

Fixed-point iteration

Definition

Rewrite f(x) = 0 as an equivalent g(x) = x. A value y with g(y) = y is a fixed point of g. Continuity of g suffices for existence; differentiability is needed only to study convergence.

xk+1 = g(xk)
Error analysis — Lagrange
ek = xk − y, y = g(y)
ek+1 = g(xk) − g(y) = g′(ξk)·ek
|ek+1| = |g′(ξk)|·|ek|

Everything hinges on keeping that factor below 1.

Theorem — local convergence

g differentiable on Iη = (y−η, y+η), y fixed point. If |g′(x)| ≤ M < 1 for every x in an interval Iδ ⊆ Iη, then xk+1 = g(xk) → y for every x₀ ∈ Iδ. Proof: iterate the estimate, |ek| ≤ Mk|e₀| → 0. Local: M < 1 is needed only on Iδ, not on all of ℝ.

Asymptotic rate
limk→∞ |ek+1| / |ek| = |g′(y)|

Linear convergence, faster the smaller |g′(y)|. If |g′(y)| = 0 exactly (as in Newton) the rate is better than linear — quadratic.

Contractions

g is a contraction on [a,b] if g is continuous, (1) g: [a,b] → [a,b] and (2) |g(x₁) − g(x₂)| < |x₁ − x₂| for all x₁, x₂ ∈ [a,b]. Contraction theorem: then there exists a unique y ∈ [a,b] with g(y) = y.

Building g in practice
g(x) = λf(x) + x, λ ≠ 0 ⇒ (g(x)=x ⇔ f(x)=0)
g′(x) = λf′(x) + 1, |g′(x)| < 1 ⇒ −2 < λf′(x) < 0

λ must have the sign opposite to f′(x), with |λ| < 2/|f′(x)|. If f′ changes sign on the interval, no constant λ works everywhere and the interval must be restricted.

Two distinct theorems · Newton as special case

The contraction theorem gives existence and uniqueness of the fixed point; the local theorem with M < 1 gives that the iteration actually reaches it from a close enough x₀. With the variable choice λ(x) = −1/f′(x) one recovers Newton, g′(y) = 0 — the locally optimal λ.

07

Fixed point for systems

Same structure

With f, g: ℝn → ℝn, transform f(x) = 0 into g(x) = x; the iteration is unchanged.

xk+1 = g(xk)
Convergence condition
‖Jg(x)‖ < 1

The analogue of |g′(x)| < 1, written with the Jacobian of g — not of f — evaluated at the solution x.

Additional requirements

The matrix norm must be compatible with the chosen vector norm — the same vector-norm / induced-norm pairing as in Chapter 1; Jg must be continuous; x₀ must lie in a sufficiently small neighbourhood of the solution.
