Numerical Methods · Chapter 4

Overdetermined systems

More equations than unknowns, A ∈ ℝm×n, m > n: least squares, normal equations, QR factorisation, Gram–Schmidt and Householder reflections — four routes to the same minimiser, ranked by numerical stability.

K(A)² → K(A) → stable
7 topic blocks · study reference sheet
01

The problem & the functional

The problem

A ∈ ℝm×n, m > n: more equations than unknowns. In general no x satisfies Ax = b exactly, so the system is replaced by minimising the residual instead of solving it.

Functional
r = Ax − b
φ(x) = ‖Ax−b‖² = (Ax−b, Ax−b)

Minimising ‖r‖² rather than ‖r‖ keeps φ smooth and quadratic, so it can be attacked with calculus — a full gradient in ℝn, not a single derivative.

Four routes, one minimiser

Normal equations, QR, Gram–Schmidt and Householder all solve the same least-squares problem. They differ only in whether ATA is ever formed, and in how the conditioning of A is carried through to the final triangular solve.

Don't confuse

K(A) is a property of the problem, an upper bound on the error; it does not judge the algorithm. Residual is a practical measure of fit (e.g. regression); it does.

02

Normal equations

Branch 1 · ATA is formed

Expand φ and set the full gradient — not a directional derivative — to zero.

φ(x) = xTATAx − 2bTAx + bTb
∇φ(x) = 2ATAx − 2ATb
∇φ(x) = 0 ⟹ ATA x = ATb

If rank(A) = n, ATA is n×n and invertible ⟹ unique solution x* = (ATA)−1ATb.

Convexity
∇²φ(x) = 2ATA, SPD if A has full rank

φ is convex ⟹ the stationary point found is the global minimum, not merely a critical point.

Geometric reading — orthogonality
ATAx − ATb = 0 ⟺ AT(Ax−b) = 0 ⟺ ATr* = 0

The optimal residual r* is orthogonal to every column of A, hence to all of range(A). Ax* is the orthogonal projection of b onto range(A) ⊂ ℝm.

Practical problem — instability
K2(A) = σ1/σn (SVD)
K2(ATA) = σ1²/σn² = K2(A)²

Going from A to ATA squares the conditioning: if A is already ill-conditioned, ATA becomes drastically unstable. Normal equations are not advisable in that case — use QR.

03

QR factorisation

Branch 2 · ATA never formed
A = QR
Q ∈ ℝm×m orthogonal (QTQ = I)
R ∈ ℝm×n upper triangular

rank(A) = rank(R): Q is invertible, so it does not change the rank. R has an active block R1 ∈ ℝn×n, upper triangular, in its first n rows, with m−n rows of zeros below.

Derivation — reducing the LS problem

Substitute A = QR and use ‖Qz‖ = ‖z‖ (Q orthogonal):

‖Ax−b‖² = ‖QRx−b‖² = ‖Q(Rx−QTb)‖² = ‖Rx−QTb‖²

With QTb = (c1, c2), c1 ∈ ℝn, c2 ∈ ℝm−n, and R in blocks: ‖Rx−QTb‖² = ‖R1x−c1‖² + ‖c2‖².

Solving the reduced system

‖c2‖² does not depend on x: it is the irreducible minimum residual, the quality of the best possible fit (e.g. R² in statistics). The first term is driven to zero by:

R1 x = c1
n×n triangular → back substitution, O(n²)
Reduced QR
Q1 ∈ ℝm×n = first n columns of Q
A = Q1R1, Q1TQ1 = I
Q1TA = R1 ⟹ R1 x = Q1Tb

Q1 avoids carrying useless blocks of zeros — the practical form actually computed.

Advantage over normal equations

ATA is never formed, the conditioning is never squared. The final system has K(R1) = K(A), because Q is orthogonal and K2(Q) = 1.

04

Gram–Schmidt

Branch 3 · orthonormal basis — the idea

Build an orthonormal basis q1,…,qn of range(A) such that each column aj is a combination of q1,…,qj: this structure is exactly what makes R1 upper triangular.

projv1(v2) = (v2,v1)/(v1,v1) · v1 = ‖v2‖cos(θ)/‖v1‖ · v1
CGS — classical
q̂j = aj − Σi<j (aj,qi) qi
qj = q̂j / ‖q̂j‖

Entries of R1: rjj = ‖q̂j‖ on the diagonal, rij = (aj,qi) for i < j, zero below.

Instability — numerical rank ≠ mathematical rank

Nearly dependent columns ⟹ aj is almost parallel to its projection ⟹ q̂j is a difference of nearly equal quantities ⟹ catastrophic cancellation: ‖q̂j‖ comes out small and unreliable. Classical GS loses orthogonality among the computed qi.

rankε(A) = #{ i : σi > ε }

Link to the SVD: singular values below the threshold are treated as noise — the same principle as low-rank truncation and PCA.

MGS — modified
aj(i) = aj(i−1) − (aj(i−1), qi) qi

Update all remaining columns immediately after each new qi, instead of projecting the original aj all at once. Equivalent in exact arithmetic; in floating point each projection acts on an already partly cleaned vector → less error accumulation across columns. It does not remove cancellation at the single critical step — that needs Householder.

05

Householder

Branch 4 · reflections — matrices
H = I − β v vT, β = 2/(v,v) = 2/‖v‖²
Hx = x − 2(w,x)w, w = v/‖v‖

H is symmetric and orthogonal (HTH = I) — not a permutation, a continuous reflection through the hyperplane orthogonal to v. vvT is an outer product ⟹ rank 1: H is a rank-1 perturbation of the identity, acting only along v and leaving the orthogonal hyperplane untouched.

Construction — zeroing a vector

Look for v such that Hx = αe1 (all components zero except the first). Setting v = x + ce1 and solving gives c = ±‖x‖.

c = sign(x1) · ‖x‖

The sign is chosen to avoid cancellation: if x is nearly parallel to e1 then x1 ≈ ±‖x‖, and this way v is always a sum of same-sign quantities, never a dangerous subtraction — the same principle as the stable quadratic formula (Ch. 1).

QR via Householder
Hn···H1 A = R ⟹ Q = H1···Hn

Successive reflections H1, …, Hn, each zeroing the entries below the diagonal of one column, acting only on the remaining submatrix.

The most stable route

No explicit subtraction of projections that could approach zero: Q is a product of clean reflections, with a sign choice that explicitly avoids cancellation — stable even for nearly linearly dependent columns.

06

Stability scale

Normal equations
K(ATA) = K(A)²

Conditioning squared — the fastest route, but the least stable.

QR / Gram–Schmidt
K(R1) = K(A)

Conditioning preserved. MGS keeps orthogonality longer than CGS, but neither removes the single-step cancellation.

Householder

Reflections with a sign choice that explicitly avoids cancellation — stable even in the critical case of nearly dependent columns.

Method comparison

Method ATA formed? Conditioning Cost Stability
Normal equations yes — ATA x = ATb K(A)² cheapest — one n×n SPD solve worst — squares ill-conditioning
Classical Gram–Schmidt no — orthonormal basis of range(A) K(A) moderate poor — loses orthogonality on near-dependent columns
Modified Gram–Schmidt no K(A) moderate better — less error accumulation, cancellation not removed
Householder QR no — orthogonal reflections K(A) highest — n reflections applied to A best — stable even for nearly dependent columns
